# Popkern TV for Windows

Windows kurulum dosyaları ve otomatik güncellemeler. / Windows installers and automatic updates.

**İndir / Download:** [Releases](https://github.com/omerfkurt55/popkerntv-desktop-releases/releases/latest) → `PopkernTV-Setup-<sürüm>.exe`

- Windows 10 (1809+) / 11, 64-bit. Yönetici izni gerekmez / no administrator rights needed.
- Uygulama yeni sürümleri kendisi bulur ve tek tıkla günceller. / The app finds new versions and updates itself.
- İlk açılışta Windows SmartScreen uyarısı çıkabilir: "Ek bilgi → Yine de çalıştır". / SmartScreen may warn on first run: "More info → Run anyway".

Popkern TV boş bir oynatıcıdır; içerik sağlamaz. Eklediğiniz kaynakların yasal sorumluluğu size aittir.
Popkern TV is an empty player and provides no content. You are responsible for the sources you add.
